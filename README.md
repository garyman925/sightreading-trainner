# 合拍｜鋼琴視奏練習室

繁體中文、純前端的鋼琴視奏練習工具，為 ABRSM Grade 4–6 程度琴手設計，集中訓練雙手配合、提前讀譜與表情記號。短譜刻意簡化，並非官方考試試題。

## 目前功能

- 27 份原創四小節短譜，包含雙手節奏、垂直讀譜、速度階梯及表情記號。
- 30–160 BPM、四拍預備拍、合成琴音示範及左右手聲部分選。
- F／J 雙手節奏按鍵比對；鋼琴音準和表情由使用者自行評估，沒有麥克風或 MIDI 偵測。
- 速度階梯：連續兩次達標後升速，未達標降速。
- p／mf／f、漸強漸弱、連奏與斷奏；可關閉的提前一拍提醒。
- 青綠游標顯示目前播放位置，金色光暈提示預讀下一小節，包含雙手音符及表情記號；最後一小節取消預讀提示。
- 本機練習紀錄、自評、筆記及 CSV 匯出。資料留在瀏覽器，不跨裝置同步。

## 啟動

需要 Node.js 18 或以上，毋須安裝套件：

```sh
npm start
```

然後開啟 http://127.0.0.1:8787 。也可以直接用瀏覽器開啟 `dist/index.html`；部分瀏覽器可能限制本機檔案的儲存功能。

## 測試

```sh
npm test
```

測試涵蓋練習拍數、譜面位置、表情音量與音長、播放流程、速度階梯、自評與紀錄、CSV，以及預讀提示切換。流程測試使用模擬 DOM 和音訊時鐘；不等同實際瀏覽器視覺或音訊驗收。

## 檔案

- `dist/index.html`：介面與操作說明。
- `dist/style.css`：響應式排版。
- `dist/exercises.js`：短譜及表情資料。
- `dist/notation.js`：SVG 大譜表、播放游標、預讀光暈。
- `dist/app.js`：播放、操作、訓練和本機紀錄。
- `tests/`：可重現的檢查。

## 發佈

這是無需建置的靜態網站，將 `dist/` 設為網站根目錄即可。儲存庫不包含原有 Sites 專案身分、憑證或個人練習紀錄。

首次部署或更換網址會使用新的瀏覽器儲存區；請先在舊版本匯出 CSV 備份。
